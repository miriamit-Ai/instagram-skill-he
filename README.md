# סוכן אינסטגרם בעברית לקלוד

**הגרסה העברית של Miriam AI** · [‎@miriamit.ai‎](https://www.instagram.com/miriamit.ai/)

13 סקילים לקלוד שמנהלים חשבון אינסטגרם, בעברית. חינם, בלי הרשמה, בלי מפתח API ובלי לחבר שום דבר.

אחד כותב לכם רילס מתוך 26 נוסחאות פתיח בעברית, ונותן ציון לפתיח לפני שאתם מבזבזים טייק. אחד מוצא את הרילס שעובדים בתחום שלכם ומדרג אותם לפי כמה כל אחד עבר את הממוצע של החשבון שלו. אחד נותן לפרופיל ציון מתוך 100 ומשכתב את מה שהוריד נקודות. אחד מתכנן לכם את השבוע.

ואחד הוא המאניש, שבזכותו כל השאר שמישים: הוא מוריד מהטקסט את הקווים המפרידים הארוכים, את הביטויים השחוקים של AI בעברית ובאנגלית ואת התווים הנסתרים, ונותן ציון למה שנשאר.

**שום דבר לא מתפרסם עד שאתם אומרים כן.** הסקילים כותבים. אתם מפרסמים.

## התקנה

מדביקים את זה בקלוד:

```
https://github.com/miriamit-Ai/instagram-skill-he

תתקין את הסקיל הזה, ואז תבדוק ש-/ig-reel עובד.
```

או ב-Claude Code:

```bash
git clone https://github.com/miriamit-Ai/instagram-skill-he.git
cp -r instagram-skill-he/skills/ig-* ~/.claude/skills/
```

או כתוסף:

```
/plugin marketplace add miriamit-Ai/instagram-skill-he
/plugin install instagram-agent-he
```

בלי Claude Code בכלל? אפשר להדביק `SKILL.md` אחד בתחילת שיחה והוא יעבוד כמצב עבודה. מפסידים את הכלים ב-Python, שהם רוב הערך של `/ig-reel` ו-`/ig-human`, אבל השאר עובד.

אחר כך משקיעים עשר דקות ב-`templates/voice.md`. מעתיקים אותו ל-`~/.claude/instagram/voice.md` וממלאים, או שולחים לקלוד שלושה רילס שלכם ומבקשים "תכתוב לי voice.md מאלה". כל הסקילים קוראים את הקובץ הזה, כולל באיזה מגדר לפנות לקהל.

## מה הותאם לעברית

- **26 נוסחאות פתיח בעברית** (`skills/ig-reel/hooks_he.json`), עם דוגמאות לקהל ישראלי, גרסה למסך, ומה הורס כל נוסחה. כל נוסחה מזהה את עצמה בפתיח עברי שנמצא ברשת.
- **ציון לפתיח בעברית** (`hookscore.py`): מילות מתח, מספרים במילים, ₪, פתיחות חלשות ("היי", "בסרטון הזה"), פנייה לצופה, ואותיות השימוש (ו, ה, ב, ל, מ, ש, כ). העברית מזוהה לבד.
- **דף תזמון בעברית** (`beats.py`): קצב ברירת מחדל של 150 מילים לדקה, שנמדד על ריל עברי אמיתי, וזיהוי לולאה שמתעלם מאותיות השימוש.
- **מאניש לעברית** (`ig-human`): ביטויים שחוקים כמו "בעולם של היום", "חשוב לציין ש" ו"מהפכני", ומבנים כמו "זה לא רק X, זה Y".
- **`/ig-reel` בעברית מלאה**, וכל שאר הסקילים עונים בעברית מדוברת, עם פנייה ברבים כברירת מחדל ובלי הסימן —.
- **תבנית קול בעברית** (`templates/voice.md`), כולל מגדר הפנייה ושילוב מילים באנגלית.

ההוראות המלאות של שאר הסקילים מתורגמות לעברית בהדרגה.

## English

A Hebrew-first Instagram skill pack for Claude by Miriam AI. Install it the same way (paste the repo link into Claude, or copy `skills/ig-*` into `~/.claude/skills/`). Every skill still answers in English when you write to it in English, and `hookscore.py`, `beats.py` and the humanizer keep their English checks alongside the Hebrew ones.
